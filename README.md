# HUHUmake Knowledge Cards

一个面向 Codex 及兼容 Agent Skills 环境的知识卡片 Skill。它把用户粘贴的文章或本地 Markdown/TXT 文本，整理成 6～10 张可复习、可继续编辑的知识卡。

## 1. 项目解决什么问题

长文章中的重点常常被叙述、重复观点和例子掩盖；普通摘要又容易把多个概念挤在一起，导致读者记不住、无法自测，也不清楚哪些内容来自原文、哪些是额外补充。

本项目通过原子化提炼和去重，把文章转换为一组结构统一的知识卡：每张卡只讲一个重要知识点，同时保留必要的条件、边界和依据，帮助读者快速理解、复习和检查自己是否真正掌握。

## 2. 主要功能

- 接收用户粘贴的文章，或读取本地 `.md`、`.markdown`、`.txt` 文件；
- 提取真正重要的知识，合并重复内容，删除口号式或仅起过渡作用的句子；
- 输出 6～10 张知识卡；每张卡只讲一个知识点；
- 每张卡包含标题、核心知识、简明解释、例子或自测问题、依据；
- 信息不足，或涉及科学、医疗、法律、金融、统计、争议性及时间敏感信息时，可在环境允许的情况下进行外部核验，并标注来源；
- 区分原文内容、外部补充和推断，必要时在卡片后附 `Sources` 清单；
- 为整组卡片提供统一的 3:4 印象派背景设计方向，包括主题、色调、光线、笔触和文字留白区域；
- 输出背景设计描述，不默认生成或导出 PNG/JPG 图片，也不负责发布内容。

暂不支持：PDF、RTF、Anki、图形界面。RTF 文件请先转换为纯文本或 Markdown；本项目也不是独立的命令行程序。

## 3. 安装方法

本项目没有第三方运行依赖，不需要安装 Python、Node.js 或额外的包。它需要在支持 Agent Skills 的 Codex 或兼容环境中使用。

将 Skill 目录复制到该环境的 Skills 目录，例如：

```bash
mkdir -p "$CODEX_HOME/skills"
cp -R ./skill/huhumake-knowledge-cards "$CODEX_HOME/skills/huhumake-knowledge-cards"
```

如果当前环境已经把本项目目录作为 Skill 项目加载，则无需复制，直接使用：

```text
./skill/huhumake-knowledge-cards/SKILL.md
```

## 4. 使用方法

在支持 Skills 的对话中调用 Skill 名称：

```text
使用 $huhumake-knowledge-cards，把下面这篇文章整理成 8 张知识卡：

[粘贴文章]
```

也可以让它读取本地文件：

```text
使用 $huhumake-knowledge-cards，读取 ./notes/sleep.md，整理成知识卡；
如果有需要核验的科学结论，请补充可靠来源并区分原文与外部信息。
```

建议明确提供以下偏好：卡片数量（6～10 张）、输出语言、是否允许外部检索，以及是否需要更适合发布的短句。若原文不足以支持 6 个独立知识点，Skill 不会为了凑数强行拆分；在允许检索时才会用相关且有来源的内容补足。

## 5. 输入输出示例

### 输入

```text
慢速练琴不是单纯降低速度，而是为了看清节奏、指法和动作中的问题。
连续弹错时，应缩小练习范围并定位原因。
```

### 输出节选

完整结果会包含 6～10 张卡；下面只展示其中一张：

```markdown
### 卡片 1｜慢练是诊断工具

- 核心知识：慢练的目的，是让演奏者有时间发现并修正具体问题。
- 简明解释：降低速度后，节奏、指法和动作更容易被分别观察。只把速度放慢、却不检查问题，并不会自动提高练习质量。
- 例子 / 自测：这一遍慢练，你准备只检查节奏、指法，还是动作？
- 印象派背景：清晨琴房，蓝灰与暖金色调，柔和侧光和可见笔触，右侧保留低对比留白供文字排版。
- 依据：原文：第 1 段
```

当使用了外部资料时，输出还会附加类似下面的来源部分，并在相关卡片中标注来源编号：

```markdown
## Sources

- S1：来源标题，作者或发布机构，发布日期（如有），https://example.com/source
```
